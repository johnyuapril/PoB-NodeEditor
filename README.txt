PoB 노드 편집기 (Path of Building PoE2 계산 엔진 사용)

실행
 1. 이 폴더를 영문 경로에 풀어 주세요. 예: C:\PoBEditor
 2. start.bat 을 더블클릭하세요. 검은 창이 뜨고 5초쯤 뒤 브라우저에 편집기가 열립니다.
 3. 다 쓰면 검은 창을 닫으세요.

쓰는 법
 - 위쪽 "예시 빌드"를 고르거나 PoB 빌드 코드를 붙여넣고 "불러오기".
 - 카드 = 빌드 요소(스킬, 보조 젬, 아이템, 패시브). "전투 상황" 카드는 최근 적 처치·피격 같은 상황 조건이며, 글자를 누르면 켜고 끕니다. 왼쪽 점 = 입력(필요한 것), 오른쪽 점 = 출력(만드는 것).
 - 선 = 출력과 입력이 맞는 연결. 선을 누르면 끊기/잇기. 끊으면 그 조건이 없는 상태로 PoB가 다시 계산합니다.
 - 카드의 입력/출력 글자를 누르면, 그걸 만드는(또는 쓰는) 노터블·고유템·보조젬 목록이 DPS/EHP 미리보기와 함께 나옵니다.
 - 굵게 빛나는 선 = 순환 고리. 오른쪽 "순환 고리"에서 기여도 측정.
 - 위쪽 숫자: 초록/빨강 = 방금 바꾼 것의 변화, "원본" = 불러온 빌드 대비.
 - "PoB 코드 만들기"로 결과를 PoB에 그대로 가져갈 수 있습니다.
 - 위쪽 "업데이트" 버튼: 새 버전이 있으면 초록색으로 깜빡입니다. 누르면 새 파일을 받아 적용하고 편집기가 저절로 다시 켜집니다(보던 빌드도 다시 불러옵니다).

들어 있는 것
 bin\      LuaJIT(Windows용), PoB의 socket.dll/z.dll
 pob\      Path of Building PoE2 소스 (v0.23.1, 그림 파일 제외)
 pob_calc\ 계산 서버와 편집기 화면
