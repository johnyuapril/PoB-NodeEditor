# 젬링 화염파 메커니즘 해석 (요약본)

> 원본은 이전 계정의 Claude Docs 문서(https://claude.ai/artifact/2Q1jRdmpcxvSroyh4Hces9)이고, 새 계정에서는 열리지 않을 수 있어서 스레드 대화를 바탕으로 핵심만 다시 적은 요약본이에요. 원본 전체가 필요하면 이전 계정에서 문서를 열고 이름 옆 메뉴의 내보내기(Markdown)로 받아 두세요.

## 대상
- poe.ninja 0.5.5 리그(Forbidden Rites) 젬링 리저네어 + 화염파(Flameblast) 메인 캐릭터 상위 4명: StickyOildUp, VorathEM, sdgfsdfshgs, TafeLynx_Gemling
- 공략 글 없이, 우리 PoB 헤드리스 계산기 + poe2db 원문 + 조건 지도만으로 해석

## 핵심 엔진: 단계 × 젬 퀄리티 → 점화 증폭
- 전직 노드 **고급 마석학**이 화염파 젬 퀄리티 효과를 "단계당 점화 강도 증폭"으로 바꿈 (퀄리티 44% → 단계당 점화 88% 증폭)
- 명중도 단계당 75% 증폭이라 피해가 단계 수의 제곱에 가깝게 늘어남
- PoB 기준 1단계 97만 → 10단계 2,379만 (24.6배). 고급 마석학만 빼도 피해 −91%
- 상위 4명 모두 전직 노드 4개와 화염파 보조젬 구성이 같음

## 보조 장치
1. 이글거리는 화염 II: 명중 피해 30%를 줄이는 대신 점화 100% 증폭. 치명타 0 빌드라 손해 없음
2. 젬 레벨: 지팡이(화염 주문 +8 등), 목걸이, 미믹의 분광기
3. 저항 감소: 원소 약화(−36%), 노출, 원소 유탄(실효 −18%) → 보스 화염 저항 사실상 음수
4. 점화 강도 593% 증가(주로 주얼)

## PoB가 계산하지 않는 것
- 회오리 + 회피 구르기 시 시전: 적 모으기
- 기름 지대: 노출 −20%, 인화성 200% 증폭, 감속. 불붙은 기름은 기름 유탄 화염 피해의 150%를 "변경 불가 피해"로 지대 점화에 더함
- 사용자 지적으로 정정된 부분: 화염파 점화가 기름 지대에 옮겨 붙으면 최초 점화 크기가 지대 점화의 바탕이 되고, 잠식하는 지대·범위 확대·다중 사격을 붙인 기름 유탄으로 불타는 지대를 넓혀 "한 방의 거대 점화가 화면 전체로 확산"되는 것이 광역 핵심. 원문/데이터로 확정은 못 했고 "정황상 성립" 수준
- 화염파는 대기시간 10초. 점화 지속 3.5초. "한 방 총량(약 8,273만 점화) + 재준비 시간"으로 평가해야 하며 PoB DPS 2,379만은 과장. 단계당 0.25초(이 빌드는 시전속도로 약 0.13초)

## 도구 개선점
- poe.ninja 코드에는 단계 수가 빠져 있어서 그대로 넣으면 PoB가 약 25배 낮게 계산 → 편집기가 단계형 스킬을 최대 단계로 기본 설정해야 함
